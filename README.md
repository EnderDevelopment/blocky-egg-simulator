# Roblox Blocky Simulator

This project is a blocky simulator for Roblox, featuring custom player movement, interactive environment objects, and a simple UI. The simulator includes a ground, walls, and blocky objects that players can interact with. The project consists of three main scripts: PlayerController.server.lua for handling player movement and camera controls, EnvironmentInteraction.server.lua for managing interactions with environment objects, and UIManager.client.lua for creating and managing the game's UI.

## Install

1. Create a new Roblox Studio project.
2. Create a Script in ServerScriptService and name it PlayerController.server.lua. Paste the content from the PlayerController.server.lua file.
3. Create another Script in ServerScriptService and name it EnvironmentInteraction.server.lua. Paste the content from the EnvironmentInteraction.server.lua file.
4. Create a LocalScript in StarterPlayerScripts and name it UIManager.client.lua. Paste the content from the UIManager.client.lua file.

## Use

1. Open the Roblox Studio project.
2. Click the Play button to start the game.
3. Use the W, A, S, and D keys to move the player around the environment.
4. Interact with the blocky objects by touching them.
